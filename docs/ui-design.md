# UIデザインの工夫

このゲームの見た目と演出の考え方をまとめます。マイクリ（My Crypto Heroes）のアートをどこで使い、どこを自分たちでベクターで描いているか、演出で力を入れたところとその理由を、画面ごとに整理しました。
バトルの見せ方の細かい仕様（役割の色・弾の種類など）は [ui.md](ui.md) にあります。

---

## 1. 基本方針

| 方針 | 理由 | 具体的には |
| --- | --- | --- |
| **主役はマイクリのアート** | 偉人ヒーロー・エネミー・レイドボスのドット絵こそが、このゲームの「らしさ」。UIはそれを引き立てる額縁にする | キャラクター・背景・アイコン・効果音はできるだけMCHの素材をそのまま使う。加工は彩度・明るさ・反転だけ |
| **足りないものはベクターで、MCHの様式に合わせて描く** | MCHに無い記号（シールド、毒の泡、地図、帯など）をドット絵で描き足すと、解像度や色味がずれて浮く。ベクターなら画面サイズに関係なくくっきりし、色をUIのテーマ色に合わせて変えられる | `assets/vfx/` のSVG（7点）、JSの中のインラインSVG、CSSのグラデーション・clip-path |
| **UIを「生きている」ように** | オートバトラーは見ている時間が長い。止まった画面は退屈に見える | 背景・帯・キャラクターが常にわずかに動く。操作には必ず動きで返す（[ui.md](ui.md) の ZZZ の分析） |
| **色の優先度をはっきり** | ドット絵とUIが同じ強さで主張すると、どこを見ればいいかわからない | 背景は彩度・明るさを落とし、エフェクトも少し落とし、UI（選択・数値・ボタン）だけ高彩度 |
| **スマホ縦画面で、スクロールしない** | 片手で遊ぶオートバトラー。スクロールが必要な画面は「探す」ストレスになる | 各画面を 100dvh に収める。Playwright で 360×640〜430×800 とPCの各サイズを毎回確認 |

### 2.2 自分たちで描いたもの（ベクター・CSS・Canvas）

| もの | 描き方 | 理由・工夫 |
| --- | --- | --- |
| シールドのアイコン | SVG（`assets/vfx/shield.svg`） | MCHに無い。MCHのバトルアイコンと同じ「丸地に白い記号」の様式で描いた |
| 毒の泡・雲・塊、血のしずく・しぶき、斬撃 | SVG（`assets/vfx/`） | 状態異常を「くらっている感」を出すため。拡大・回転・色かけをしても崩れない |
| バトルの地面（陣地・前衛/中衛/後衛の線・中央線） | 実行時にSVGで描く（`fieldFloor()`） | 地面の座標を7°回転させて遠近をつけ、両陣営を斜めに向かい合わせる。画面サイズに合わせて計算し直せる |
| バトルの背景の帯（リボン） | インラインSVGの記号＋HTMLの文字（`battle-backdrop.js`） | ゼンレスゾーンゼロのUIのような「デザインされた帯」。★・≫・バーコード・照準などの記号と、部隊名・ステージ番号を流す |
| ワールドマップの大陸 | SVGの多角形（`CONTINENTS`） | 時代ごとに国境が違うので、写実的な地図ではなく記号的な大陸にした。グリッドと走査線でタイムマシンの画面らしく |
| ルートマップの道 | 実行時にSVGの線（下線＋破線） | 枝分かれ・交差しない道を、レーン数に関係なく描ける。通った道は流れる破線で光らせる |
| 特異点（特別ステージ）のピン | CSSの破線の輪2つ＋ボスの絵 | 逆向きに回る輪と、赤・水色の色ずれ（グリッチ）で「ありえない場所」を表す |
| 宝箱 | インラインSVG | 開く動きを付けるため（ふたを開ける）。色はMCHの金宝箱のモーダルと同じ金のグラデーション |
| パネル・ボタン・チップ | CSS（clip-path・グラデーション） | 角を切り落としたガジェット風。左上が明るく右下が暗いエッジで「物」に見せる |
| HPバー・役割の円・ウェーブのゲージ | CSS | HPバーは台形、ボスのウェーブのマスは赤。数値の情報はすべてUI側の色で |
| タイムマシンのシルエットと実体化 | Canvas（`machine-reveal.js`） | 合体ロボの64×64のドット絵を、パーツの割合だけ下からドット単位で実体化する。ドット絵の素材を「進み具合のゲージ」に変える |
| 背景の層（網点・斜線・粒子・ビネット） | CSS＋Canvas（`ambient.js`） | MCHの背景を暗くしたうえに重ね、画面を切り替えても動き続ける |
| 南京錠・スピーカーなどの小さなアイコン | インラインSVG | 線の太さと色をUIに合わせるため |

**線引き**: 「キャラクターと世界」はMCHのアート、「情報と記号」はベクター。プレイヤーが見て楽しむものはドット絵、読んで判断するもの（HP・役割・相性・道）はくっきりしたベクターにしています。

## 3. 演出で力を入れたところ

### 3.1 バトル: 誰が・誰に・何をしたか

- **理由**: オートバトルは勝手に進むので、何が起きたかわからないと「見ているだけ」になる。負けた理由がわからないと、次の買い物に活かせない
- **工夫**
  - 発動したヒーローが踏み込み、足元の円が役割の色で光り、頭上に「アイコン＋役割」が出る
  - 役割ごとに違う飛び方（攻撃は光の尾、毒は放物線の塊、回復は十字の粒、強化は光線）で対象へ飛ぶ
  - 結果は事前に確定しているので、弾が当たるまでHPと状態異常の表示だけを止める（最長0.7秒）。数字の変化と着弾の見た目がずれない
  - HPバーは白い残像が遅れて減る（「当たった感触」）。大きなダメージでは画面と背景が揺れ、ダメージ数値は割合に応じて大きくなる
  - ×2 では弾を速く、×4 では弾と役割の表示を省き、着弾だけにする（早送りでも重くならない）

### 3.2 バトル: 背景が流れ続ける

- **理由**: バトル中に画面の大部分が止まっていると、ドット絵の小さな動きだけでは迫力が出ない
- **工夫**: MCHの色違いのバトル背景をゆっくりパンさせ、その上に6本の帯を違う速さ・角度で流す（いちばん奥に大きな袋文字「BATTLE ★ STAGE nn」）。帯は半透明で彩度を抑え、UIより目立たせない

### 3.3 毒・出血を「くらっている感」

- **理由**: 毒・出血はスタックが増えて効いてくる状態異常なので、数字だけでは怖さが伝わらない
- **工夫**: 毒は陣地が紫に濁って泡が上り、HPバーに紫の斜線が流れる。出血は陣地の縁が心拍のように脈打ち、血が垂れる。スタックが多いほど濃くなる

### 3.4 レイドボス

- **理由**: ノードの最後の目標。通常のウェーブとはっきり違う「事件」にしたい
- **工夫**
  - 出撃前の会話でボスが画面に落ちてきて（揺れ・フラッシュ）、マーケットでは「WARNING / RAID BOSS」の赤いテロップ、ウェーブのゲージの最後のマスが赤
  - 盤面では中衛の中央に2.3倍で描き、赤く光りながら呼吸する。次に使うスキルを頭上に出し、大技は「FINAL」で点滅して予告、発動時は画面いっぱいの帯と強い揺れ
  - BGMがレイドの曲に切り替わる

### 3.5 マーケットの単純作業に手触り

- **理由**: 買う・合成する・売るは何十回も繰り返す。ここが気持ちよくないと遊び続けられない
- **工夫**: 買ったカードは弧を描いて枠へ飛ぶ。合成は素材が1か所に集まって「LV UP!」と光がはじける。売るとカードが縮んで消え、コインがGUM表示へ飛ぶ。GUMはカウントアップ。まだ買えるヒーローが残っている間は「バトル開始」を控えめにして、強化し忘れを防ぐ

### 3.6 ストーリーの会話

- **理由**: 歴史上の偉人と出会うのが、ストーリーの楽しみの中心
- **工夫**
  - 立ち絵は2体まで（左はクリス固定、右は相手）。スマホでも重ならない。右の相手は反転してクリスの方を向く
  - 喋っていない方は暗くし、喋る方は小さく跳ねる。台詞は1文字ずつ出る
  - 64pxのヒーローのドット絵は、等身の違う立ち絵と並べても浮かないよう、影の台座に乗せて小さめに置く
  - タイムスリップは逆向きに回る破線の輪と、逆回りの時計の針で表す（1.85秒）
  - ノードごとの台本（看板ヒーローとの出会い・レイドボスの第一声・クリア）と、ほかのヒーローの自己紹介の一言

### 3.7 タイムマシンの改良（パーツ画面）

- **理由**: パーツは数ノードに1つの大きな報酬。数字の「1/3」では手応えがない
- **工夫**: 次の合体ロボを黒いシルエットで出し、パーツの割合だけドットを下から実体化させる（いちばん新しい帯は白く光る）。そろったら名前が明かされ、改良の会話では古い機体が光って消え、新しい機体が金色に光って現れる

### 3.8 ルートマップ（参考作 のような枝分かれ）

- **理由**: ルートを選ぶ判断材料（種類・地形・エネミーの傾向・相性）を、地図の上で一目でわかるようにしたい
- **工夫**: 各ステージのタイルには、そこで出会うヒーロー・出てくるエネミー・ボスのドット絵を出す（まだ出会っていないヒーローは白いふちのシルエット）。地形のバッジ、強敵の「強」、次に行けるステージは脈打つ。選んだステージのカードに相性の印（◎○－）。通った道は流れる破線で光る

### 3.9 特異点（特別ステージ）

- **理由**: 本編とは違う「隠し要素」。開いたことに気づいてほしい
- **工夫**: 開くまで地図に出さない。開くとクリアの会話の最後にマインが特異点の出現を告げ、地図には回転する輪とグリッチするボスの絵が現れる（`rift-in` で裂け目が開くように出る）

### 3.10 画面の切り替え・テロップ

- **理由**: 画面の切り替えは待ち時間。短く、気持ちよく
- **工夫**: 斜めの帯のワイプ（約0.6秒。中央にマイクリくん）。ステージ開始・勝敗・結果は斜めの帯のテロップの手前にキャラクターを重ねる（UIを「空間の一部」として扱う）

## 4. 色・質感・文字

### 4.1 彩度の段階（奥ほど落とす）

| 層 | フィルター | 理由 |
| --- | --- | --- |
| 画面の背景（常に残る層） | 彩度 0.5・明るさ 0.42 | UIのいちばん後ろ。雰囲気だけ伝われば十分 |
| バトルの背景 | 彩度 0.9・明るさ 0.62（＋陣営の色の網掛け） | バトルは画面全体を盛り上げたいので少し明るく |
| 会話の背景 | 彩度 0.85・明るさ 0.72 | 「その時代に来た」ことが伝わるように、背景をよく見せる |
| 喋っていない立ち絵 | 明るさ 0.55・彩度 0.7 | 誰が喋っているかを一目で |
| バトルのエフェクト | 彩度 0.75・不透明度 0.85 | 着弾の演出がドット絵やHPの数字を隠さないように |
| UI | 高彩度（シグナルイエロー #ffd23f、シアン、マゼンタ） | 選択・合成可能・ダメージ数値など、大事な情報ほど明るく |

プレイヤーのテーマ色（クリス=緑、マイン=水色、MAI=紫）は、HUDの枠・吹き出しの縁・粒子の色に使います。ノードにもテーマ色があり、ピン・ステージ結果のアクセントに使います。

### 4.2 文字

- 見出し・テロップ: Dela Gothic One（太く、ドット絵と並べても負けない）
- 数値・英字ラベル: Chakra Petch（ガジェット・計器らしい字形）
- 英字の大きな袋文字（-webkit-text-stroke）を背景に敷き、手前にキャラクターや見出しを重ねて奥行きを出す

### 4.3 ドット絵の扱い

- MCHのドット絵は `image-rendering: pixelated` で拡大し、ぼかさない
- 64pxのヒーロー・合体ロボはできるだけ整数倍に近い大きさにする（ドットの大きさがそろう）
- 高解像度のイラスト（MAI）は pixelated にしない

## 5. 演出の速さと、遊びやすさ

- 演出は「短く、でも省かない」。切り替え約0.6秒、情報バーのめくり0.5秒、ヘルプのめくり0.6秒、VSは1.5秒（タップで飛ばせる）
- バトルの速さ（×1/×2/×4）に合わせて演出を間引く。パッシブのカットインは ×1 のときだけ
- 端末の「視差効果を減らす」設定が有効なときは、CSSのアニメーション、バトルの背景の帯・パン、毒・出血のもや、背景の粒子を止め、タイムマシンの実体化は最後の状態から始める
  - まだ対応していないもの: JS（Web Animations API）で動かしている演出（カードが飛ぶ・合成の光・弾・血しぶき・毒の雲・画面の揺れ）、スプライトのコマ送り、紙吹雪、文字送り。今後の課題

## 6. 音

| 場面 | 曲（MCH） |
| --- | --- |
| タイトル・プレイヤー選択・ワールドマップ | PvP |
| マーケット | ランド |
| バトル | PvE |
| レイドボスのウェーブ（マーケット・バトル）、特別ステージのバトル | レイド |

- MCHのBGMは4曲しかないので、ストーリーでは**時代ごとに音色を変えて**ノードの雰囲気を出す（`js/engine/world.js` の `ERAS[].tone`、`areaMusic`）
  - 近代: そのまま / 近世: 少し低く（再生速度0.96）/ 中世: さらに低く、高い音を少し削る（0.93・7000Hz）/ 古代: いちばん低く、こもった音（0.9・5200Hz）/ 時空のはざま: 少し高く速く（1.06）
  - 古い時代ほど「遠い昔の記録を聴いている」ように。同じ時代の中では、ノードごとにマーケットとバトルの曲を入れ替えて変化をつける（例: 近世・新大陸と海のバトルは PvP の曲）
- 効果音は同じ音が90ms以内に重ならないようにする（オートバトルで音が割れないように）
- ブラウザの自動再生の制限があるので、最初のタップで鳴り始める。タイトル右上で消音
