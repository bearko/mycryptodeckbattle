# MVP 設計メモ

参考作 の仕組み（`docs/research.md`）を、My Crypto Heroes のアセットで再現した CPU 戦 MVP の設計です。
数値はすべて `js/engine/balance.js` に集約しています。

## スコープ

| 区分 | 内容 |
| --- | --- |
| 実装した | プレイヤー選択（3人）、マーケット（ヒーロー4枠＋マテリアル1枠、更新、取り置き、売却）、合成（Lv1×3→Lv2、Lv2×2→Lv3、Lv4はクリプトエナジーのみ）、合成時のエクステンション3択、パーティ6枠＋控え4枠、配置（タップ / ドラッグ）、パーティHP共有のオートバトル、シールド・出血・毒・回復・チャージ操作・効果量の増減、隣接効果、同時発動の解決順、サドンデス、ライフと敗北時の減少、復活、宝箱（ステージ3・6・9）、10勝でクリア、セーブ/つづきから、BGM・SE・エフェクト |
| スコープ外 | オンライン対戦（非同期PvP、ランク） |
| 未実装（今後） | 戦闘不能 / バリア（Knockout / Protect）、Shiny、進化、Mythical、図鑑、Extended Mode、オーバーフロー（満杯時の仮置き） |

## 参考作 から引き継いだルール

- 10勝でクリア、開始ライフ10、敗北時のライフ減少（1〜2: 1、3〜4: 2、5以降: 3）、1回だけの復活
- マーケット5枠（ヒーロー4＋マテリアル1）、更新3GUM、取り置き、マーケットランク＝ステージ数（出現率表も同じ）
- 取り置きは1枠ずつ（GUMが足りなくてもでき、更新でも次のステージでも残る。買うか解除するまで続く）。調査では参考作のロックは「ラインナップ全体を翌日に持ち越し」と記録していたが、欲しいヒーローだけ残せるよう1枠ずつにした。全枠取り置き中は更新できない
- 合成のレシピ、Lv倍率（1/2/3/4）、売却額（価格×コピー数[1,3,6,12]÷2 切り上げ）
- 6枠（3×2）のパーティ、上下左右の隣接、控え4枠
- 共有HP、チャージ（クールダウン）、同時発動は シールド→ダメージ→状態異常→回復、同時決着はプレイヤー側有利
- 出血（0.5秒毎にスタック数ダメージ→1減少）、毒（1秒毎、減少なし）、状態異常ダメージはシールドに15%軽減
- 30秒でサドンデス

## ヒーロー / エネミーのスキル生成

マイクリのヒーローは「攻撃はエクステンションのアクティブスキル、ヒーロー固有なのはパッシブスキル」という構造のため、
パッシブスキルだけを変換すると支援役ばかりになります。そこで次のように組み立てています（`scripts/build_data.py`）。

1. **メイン効果（チャージで発動）**: ステータスの傾向で決定
   - HPが上位20%かつ攻撃系が低い → シールド
   - PHY型 → ダメージ（AGIが高ければ出血）
   - INT型 → パッシブが回復系なら回復、シールド系ならシールド、妨害系なら毒、それ以外はダメージ
2. **サブ効果**: マイクリのパッシブスキル文を分類して変換
   - ダメージ → ダメージ / 回復・復活 → 回復 / バリア・デコイ → シールド / 毒 → 毒 / 出血 → 出血
   - 睡眠・混乱・恐怖・バインド・AGIダウン → チャージダウン / AGI・チャージアップ → チャージアップ
   - PHY・INTアップ → 効果量アップ / PHY・INTダウン → 効果量ダウン
   - パッシブの発動条件が「バトル開始時」なら、サブ効果もバトル開始時に1回発動
3. **チャージ時間**: AGIの順位から 3.0〜7.5秒
4. **効果量**: レアリティごとの「1秒あたりの予算」×チャージ時間×配分（メイン65%/サブ35%）×Lv倍率を、種別ごとの換算式で数値化

エネミーは、エネミーのアクティブスキル文を同じ分類にかけ、画像の重複を除いた代表を能力値の順位で5段階のレアリティに分けています。

## CPU対戦相手

参考作 の「同じ日数の他プレイヤーの盤面」を、ステージ1から同じルールで買い物をする仮想プレイヤーで再現しています（`js/engine/cpu.js`）。

- エネミーだけのプールを使い、同じ収入・同じマーケット確率で購入・合成・売却
- 宝箱・マテリアル・プレイヤースキルを使わない分、ステージ5以降に少しだけ追加GUM
- クエストのシードとステージ番号から決まるため、同じステージを読み込み直しても同じ相手になる

## バランス確認

`npm run simulate` で、自動プレイ（貪欲に買うだけの単純なAI）でクエストを回して集計できます。
現状の目安（900周）: クリア率 約15%、バトル時間の中央値 約12秒、サドンデス到達 約2%。
人間のプレイヤーは合成狙い・配置・エクステンション選択でこれより高い勝率になる想定です。
