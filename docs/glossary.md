# 用語対応表（参考作 → マイクリ用語）

ゲーム内のすべての専門用語を、My Crypto Heroes（マイクリ）の用語に置き換えています。
マイクリに対応する用語がないものは「独自」と書いています。

| 参考作 | 本作での呼び方 | 根拠・補足 |
| --- | --- | --- |
| 参考作（自分のチーム） | **ヒーロー** | マイクリの偉人ヒーロー（オリジナル193体。版権コラボの猿田彦は除外）をそのまま使用 |
| 参考作（対戦相手） | **エネミー** | マイクリのエネミー画像（199体。版権コラボのゴースト・猿田彦は除外）を使用 |
| Trainer | **プレイヤー** | クリスくん / マインちゃん / MAI の3人 |
| Trainer ability | **プレイヤースキル** | |
| Run | **クエスト** | マイクリのクエスト（PvE）になぞらえた |
| Day | **ステージ** | |
| Gold（$） | **GUM** | マイクリのゲーム内通貨 |
| Shop | **マーケット** | マイクリのマーケット |
| Shop rank | **マーケットランク** | |
| Reroll | **ラインナップ更新** | |

| Sell | **売却** | |
| Team / Board | **パーティ** | |
| 盤面の位置（3×2） | **前衛・中衛・後衛 × 2段** | マイクリの隊列（先頭・中衛・最後尾） |
| Bench | **控え** | |
| 共有HP | **パーティHP** | マイクリの「味方全体のHP合計」 |
| Ability | **スキル** | 名前はヒーローのマイクリのパッシブスキル名（エネミーはアクティブスキル名） |
| On Cast（クールダウン） | **チャージ**（チャージ◯秒） | マイクリのCHARGE |
| Cooldown | **チャージ時間** | ヒーローのAGIが高いほど短い |

| Merge | **合成** | |
| Level | **Lv** | |
