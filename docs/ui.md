# UI 設計メモ（「生きている」UI）

『ゼンレスゾーンゼロ』のUI分析で挙げられている考え方（手触り感・世界観との一体化・操作へのフィードバック）を、このゲームにどう当てはめたかをまとめます。

## 1. ユーザーの期待を超えるリアクション

| 考え方 | 実装 |
| --- | --- |
| 動的なカメラワーク | プレイヤー選択では、表示のたびにカメラ位置・ズーム・傾き・背景帯の角度・ポーズをランダムに変える（`cameraVariant()`）。スワイプ／タブで切り替え |
| キャラクターが喋る | トーストの代わりにプレイヤーキャラが吹き出しで喋る（`js/ui/speech.js`）。吹き出しの大きさはセリフの長さに合わせて伸縮し、次のセリフでは今の形から変形。喋っている間は口パクGIFに切り替える。セリフはキャラごとに口調を変えている（`js/ui/lines.js`） |

## 2. テクスチャと質感

| 考え方 | 実装 |
| --- | --- |
| 物質感 | パネル・カード・ボタンにエッジのハイライト（左上が明るく右下が暗い）を入れ、角を切り落としたガジェット風の形にする。パネル右上には留め具のブラケット |
| レイヤーの重なり | タイトルロゴの後ろに英字の大きな「DECK」、選択画面では名前の英字の手前にキャラクター、ステージ開始・勝敗・クエスト結果のテロップ帯の手前にキャラクターを重ねる |

## 3. ストレスを心地よさに変えるアニメーション

| 考え方 | 実装 |
| --- | --- |
| 短い尺のめくり | 画面遷移は斜めの帯のワイプ（約600ms）。情報バーは選択が変わるたびにページをめくるように差し替え（500ms）。ヘルプはタブ／スワイプでページをめくる（600ms） |
| 単純作業に演出 | 購入: カードがマーケットから枠へ弧を描いて飛ぶ。合成: 合成素材が1か所に集まって「LV UP!」と光がはじける。売却: カードが縮んで消え、コインがGUM表示へ飛ぶ。ラインナップ更新: カードを配り直すようにめくれて出る。GUMは増減をカウントアップ表示。枠の入れ替えはカードがすべって入れ替わる |
| バトル | VS演出（斜めに割れた画面にキャラ、VSが叩きつけられて画面が揺れる）、大きなダメージで画面と背景が揺れる、HPバーは白い残像が遅れて減る、ダメージ数値は割合に応じて大きくなる、発動したスキル名を小さく表示 |

## 4. UIを「死なせない」

- 背景は画面を切り替えても残り続けるレイヤー（`js/ui/ambient.js`）で、背景画像のゆっくりしたパン、漂うパーティクル、網点と斜線の流れを常に描く
- パーティのヒーローは位相をずらして呼吸するように上下し、HUDの下線には光が流れ、バトル開始ボタンには斜線が流れる
- タイトルには流れ続けるテロップ帯

## 5. 色使いの優先度

- 背景画像は彩度 50%・明るさ 42% まで落とし、バトルのエフェクトスプライトも彩度を落として半透明にする
- UIは高彩度（シグナルイエロー #ffd23f、シアン、マゼンタ）で、選択・合成可能・ダメージ数値など重要な情報ほど明るい色にする
- プレイヤーごとのテーマ色（クリスくん=緑、マインちゃん=水色、MAI=紫）をHUDのアイコン枠・吹き出しの縁・パーティクルに使う

## その他

- スマホ縦画面基準で、各画面は 100dvh に収まりスクロールしない（リストとヘルプ・詳細の説明だけスクロール）
- 文字は見出し・テロップに Dela Gothic One、数値・英字ラベルに Chakra Petch（Google Fonts）
- 端末の「視差効果を減らす」設定が有効なときはアニメーションを止める
