# UI 設計メモ（「生きている」UI）

> 全体の方針・MCHのアートとベクターの使い分け・演出の理由は [ui-design.md](ui-design.md) にまとめています。この文書はその詳細（ZZZ の分析の当てはめ方・バトルの見せ方）です。

『ゼンレスゾーンゼロ』のUI分析で挙げられている考え方（手触り感・世界観との一体化・操作へのフィードバック）を、このゲームにどう当てはめたかをまとめます。

## 1. ユーザーの期待を超えるリアクション

| 考え方 | 実装 |
| --- | --- |
| 動的なカメラワーク | プレイヤー選択では、表示のたびにカメラ位置・ズーム・傾き・背景帯の角度・ポーズをランダムに変える（`cameraVariant()`）。スワイプ／タブで切り替え |
| キャラクターが喋る | トーストの代わりにプレイヤーキャラが吹き出しで喋る（`js/ui/speech.js`）。吹き出しの大きさはセリフの長さに合わせて伸縮し、次のセリフでは今の形から変形。喋っている間は口パクGIFに切り替える。セリフはキャラごとに口調を変えている（`js/ui/lines.js`） |

## 2. テクスチャと質感

| 考え方 | 実装 |
| --- | --- |
| 物質感 | パネル・カード・ボタンにエッジのハイライト（左上が明るく右下が暗い）を入れ、角を切り落としたガジェット風の形にする。パネル右上には留め具のブラケット |
| レイヤーの重なり | タイトルロゴの後ろに英字の大きな「DECK」、選択画面では名前の英字の手前にキャラクター、ステージ開始・勝敗・クエスト結果のテロップ帯の手前にキャラクターを重ねる |

## 3. ストレスを心地よさに変えるアニメーション

| 考え方 | 実装 |
| --- | --- |
| 短い尺のめくり | 画面遷移は斜めの帯のワイプ（約600ms）。情報バーは選択が変わるたびにページをめくるように差し替え（500ms）。ヘルプはタブ／スワイプでページをめくる（600ms） |
| 単純作業に演出 | 購入: カードがマーケットから枠へ弧を描いて飛ぶ。合成: 合成素材が1か所に集まって「LV UP!」と光がはじける。売却: カードが縮んで消え、コインがGUM表示へ飛ぶ。ラインナップ更新: カードを配り直すようにめくれて出る。GUMは増減をカウントアップ表示。枠の入れ替えはカードがすべって入れ替わる |
| バトル | VS演出（斜めに割れた画面にキャラ、VSが叩きつけられて画面が揺れる）、大きなダメージで画面と背景が揺れる、HPバーは白い残像が遅れて減る、ダメージ数値は割合に応じて大きくなる、発動したスキル名を小さく表示 |

## バトルの見せ方

### 盤面（向かい合っている感）

- 参考作のように、手前に自分・奥に敵が向かい合う盤面にした。地面の座標を少し回転（7°）させて遠近をつけて画面に写すので、両陣営が斜めに向かい合い、奥のヒーローほど小さい（`js/ui/battle-view.js` の `FIELD` / `project()`）
- パーティの列（前衛・中衛・後衛）を奥行きの段にし、中央線に近い列が前衛。2段は左右に並べ、列ごとに左右の広がりを変えて重なりを減らす
- 地面は SVG で描き、陣地の色分け・各列の線（前衛は実線）・中央線を引く。列の端に「前衛・中衛・後衛」の札

### 誰が・誰に・何をしたか

| 役割 | 色 | 発動者 → 対象 | 着弾 |
| --- | --- | --- | --- |
| 攻撃 | オレンジ | 光の尾を引く弾 → 敵のHPバー | 衝撃の光・MCHの単体ダメージ演出・ダメージ数値 |
| 回復 | 緑 | 光の粒（＋） → 味方のHPバー | HPバーが緑に光る・MCHの回復演出 |
| 防御（シールド） | 水色 | 盾 → 味方のシールド表示 | シールド表示が弾む |
| 出血 | 赤 | 血のしずく → 敵のHPバー | 斬撃・血しぶき |
| 毒 | 紫 | 毒の塊（放物線） → 敵のHPバー | ドクロの雲・泡 |
| 強化・加速 | 黄 | 光線 → 隣の味方 | MCHのバフアイコン・光が走る |
| 減速・弱体 | 赤橙 | 点線 → 敵のヒーロー | MCHのデバフアイコン・震える |

- 発動したヒーローは敵の方へ踏み込み、足元の円が役割の色で光り、頭上に「アイコン＋役割」が出る
- ヒーローの足元の円・左下のアイコン・チャージゲージは常に主な役割の色
- 結果はバトル前に確定しているので、弾が着弾するまでHP・状態異常の表示だけを発動前の値で止めている（最長0.7秒）
- ×2 では弾を速く、×4 では弾・役割の表示を省いて着弾の演出だけにする

### 背景（帯が流れ続ける）

- MCHの色違いのバトル背景（2105・2405・2805・2705・2301・2205・2605・2505・2905）をステージごとに順番に使い、ゆっくりパンさせる。敵側は赤、味方側は水色に寄せて網点を重ねる
- その上にゼンレスゾーンゼロのUIのような「デザインされた帯」を斜めに重ね、それぞれ違う速さ・向きでゆっくり流し続ける（`js/ui/battle-backdrop.js`）
  - 黒地に黄色のタイトルテープ（★・≫・///・バーコード・ステージ番号）
  - 黄黒の注意テープ（交差させる）
  - 赤い敵陣の帯（相手の部隊名・照準）、水色の味方の帯（自分の部隊名・前衛・中衛・後衛）
  - 細い番号のテープ、いちばん奥に大きな袋文字「BATTLE ★ STAGE nn」
- 記号はベクター（SVG）、文字はHTML。帯は半透明でUIより控えめにし、UIの色を優先させる

### 毒・出血を「くらっている感」

- 状態異常のスタックは MCH のアイコン（ドクロ・血のしずく）で表示
- 毒: 陣地の地面が紫に濁り、紫のもやと泡が上る。HPバーに紫の斜線が流れる。ダメージのたびにドクロの雲が湧き、ヒーローが紫に染まって身をよじる
- 出血: 陣地の縁が心拍のように赤く脈打ち、上から血が垂れる。HPバーが赤く点滅。ダメージのたびに血しぶきが飛び、ヒーローが赤く染まって震える
- MCH に無かった素材（シールドアイコン、毒の泡・雲・塊、血のしずく・しぶき、斬撃）は `assets/vfx/` にベクター（SVG）で用意した。シールドアイコンは MCH のバトルアイコンと同じ「丸地に白い記号」の様式

## マーケットの取り置き・結果画面の振り返り

- 取り置きは各枠の南京錠をタップ（GUMが足りなくてもできる）。取り置いた枠は黄色い縁と「取置」の帯で示し、更新・次のステージでも残る。ヒーローを選ぶと情報バーにも「取置／解除」が出る（買えないときは取置を強調）
- まだ買えるヒーロー（GUMが足り、置き場所か合成先がある）が残っている間は「バトル開始」を控えめな色にし、買える枠に細い縁をつける（強化せずに進んでしまうのを防ぐ）
- 結果画面に「相手」「自分」のパーティを前衛→後衛の順に並べ、タップでそのバトルでのスキル（エクステンション・Lv反映後の数値）、チャージ時間、発動回数、活躍度、バトル中の効果量の増減、MVPを確認できる

## 4. UIを「死なせない」

- 背景は画面を切り替えても残り続けるレイヤー（`js/ui/ambient.js`）で、背景画像のゆっくりしたパン、漂うパーティクル、網点と斜線の流れを常に描く
- パーティのヒーローは位相をずらして呼吸するように上下し、HUDの下線には光が流れ、バトル開始ボタンには斜線が流れる
- タイトルには流れ続けるテロップ帯

## 5. 色使いの優先度

- 背景画像は彩度 50%・明るさ 42% まで落とし、バトルのエフェクトスプライトも彩度を落として半透明にする
- UIは高彩度（シグナルイエロー #ffd23f、シアン、マゼンタ）で、選択・合成可能・ダメージ数値など重要な情報ほど明るい色にする
- プレイヤーごとのテーマ色（クリスくん=緑、マインちゃん=水色、MAI=紫）をHUDのアイコン枠・吹き出しの縁・パーティクルに使う

## その他

- BGM: タイトル・プレイヤー選択はMCHのPvPのBGM、マーケットはランドのBGM、バトルはPvEのBGM。ブラウザの自動再生制限のため、タイトルのBGMは最初のタップで鳴り始める。タイトル右上のスピーカーで消音を切り替えられる
- バトル開始のVS演出は盤面と同じ並び（敵が上・右寄り、自分が下・左寄り）

- スマホ縦画面基準で、各画面は 100dvh に収まりスクロールしない（リストとヘルプ・詳細の説明だけスクロール）
- 文字は見出し・テロップに Dela Gothic One、数値・英字ラベルに Chakra Petch（Google Fonts）
- 端末の「視差効果を減らす」設定が有効なときはアニメーションを止める
