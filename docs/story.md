# ストーリーモード 仕様と開発ロードマップ

いただいた世界観・ストーリー・チュートリアルの設定をもとに、ゲームの仕様として整理したものです。
**（決め）** と書いた箇所は、設定に書かれていない部分を開発側で仮に決めたところです。変更しやすいよう、数値や並びはデータ（`js/engine/world.js`）にまとめます。

---

## 1. 世界観

- さまざまな時代・さまざまな国にエネミーが出没し、歴史に介入している
- 歴史上の偉人（ヒーロー）を仲間にしながらエネミーと戦い、世界に平穏を取り戻す

## 2. ストーリー（プロローグ）

1. クリスくんが街を歩いていると、偶然エネミーと遭遇する
2. 未知との出会いに困惑しているところへ、マインが助けに入る（「道との出会い」は「未知との出会い」と解釈）
3. マインがクリスに、世界中の歴史にエネミーが介入していることを説明する
4. マインは自分が発明したタイムマシン（MCHのエクステンション「合体ロボ」シリーズ。最初は Common の **魔導機械エメ・ラ・ルド・テレスター(破)** の名前とアート）を見せ、各時代のヒーローを仲間にしながらエネミーと戦ってほしいとお願いする
5. 幼なじみのよしみで、クリスはマインに協力することにする

## 3. ゲームの構成

```
タイトル
 ├─ ストーリー（新規）
 │   プロローグ → タイムマシン → ワールドマップ → ノード（時代×地域）→ ステージ（X-1〜X-10）→ ウェーブ（マーケット＋バトル）
 └─ フリーバトル（これまでの「10勝でクリア」のクエスト。そのまま残す）（決め）
```

| 用語 | 意味 |
| --- | --- |
| ノード | 時代×地域（例: 近代・日本）。ステージが10個（近代・日本だけ3個）。コード上は area と呼んでいる |
| ステージ | 1回の出撃。決まった数のウェーブを最後まで勝ち抜くとクリア |
| ウェーブ | マーケットでの準備＋エネミー部隊とのバトル1回 |
| レイドボス | ノードの最終ステージの、最後のウェーブで待つ大きなエネミー（MCHのレイドボス） |
| タイムマシン | 合体ロボシリーズ。Common → Uncommon → Rare → Epic → Legendary と改良していく |
| パーツ | タイムマシンの部品。ノードを初めてクリアする（レイドボスを倒す）と1つ手に入る |
| コレクション | 仲間にしたヒーロー |
| デッキ | ステージに連れて行くヒーロー。マーケットにはデッキのヒーローだけが並ぶ |

## 4. ステージ（ウェーブ制）

- ノードのステージ数は10（近代・日本はチュートリアルなので3）。3〜5ステージだと初心者用ヒーローを育てるだけで最後まで進めてしまうため（設定どおり）
- ウェーブ数: 近代・日本は 1-1: 3、1-2: 4、1-3: 5。ほかのノードは X-1〜3: 3、X-4〜7: 4、X-8〜10: 5（決め）
- 最終ステージ（X-10、近代・日本は 1-3）の最後のウェーブはレイドボス（7章）
- 各ウェーブは、これまでと同じ「マーケットで購入・合成・配置 → オートバトル」
- 最後のウェーブまで勝てばステージクリア。ライフは3、負けると1減り、0で撤退（やり直し可）（決め）
- マーケットに並ぶのはデッキのヒーローだけ。エネミーはノードごとに決まった顔ぶれから出る
- **マーケットの空き枠**（近代・日本以外）: 各枠のレアリティはランクの出現率で決まり、そのレアリティ以上のヒーローがデッキにいないと、その枠は空になる（デッキにいるいちばん近い上のレアリティで代わりに並ぶ）。難しいステージほどランクが上がるので、高レアリティの仲間をデッキに入れないと戦えない（決め。初心者用ヒーローだけで進めてしまわないため）
- 難しさ d はノードの時代とステージ番号で上がる（ノードの difficulty ＋ 2ステージごとに1）。同じ時代の後から行くノードは、最初のノードで強い仲間が増える分だけ高い（決め）
  - プレイヤー: マーケットランク ＋2d、毎ウェーブの収入 ＋(2d＋6)
  - エネミー部隊: マーケットランク ＋d、収入 ＋(2d−2)（チュートリアルのノードはさらに弱め）
  - 数値は `js/engine/balance.js` の `STORY_BALANCE`
- プレイヤーはクリスくん固定（プレイヤースキル「ガッツ」: 無料更新）、マインはナビ役（決め）
- 宝箱は出ない（ステージクリアの報酬に置き換え）（決め）

## 5. タイムマシンとパーツ

パーツは**ノード**を初めてクリアしたとき（最終ステージのレイドボスを倒したとき）に1つ手に入ります。途中のステージや2回目以降のクリアでは手に入りません。

| レベル | 合体ロボ | 改良に必要なパーツ | 改良すると行ける場所 |
| --- | --- | --- | --- |
| 1 | Common 魔導機械エメ・ラ・ルド・テレスター(破) | — | 近代（最初は日本。日本をクリアするとヨーロッパ・アメリカ） |
| 2 | Uncommon 魔導海底探索機ジャンヌ・ザ・オメガ | 2 | 近世（日本 → クリアするとヨーロッパ・新大陸と海） |
| 3 | Rare 魔導戦車ジュウ・ザ・トロール | 3 | 中世（日本 → クリアするとヨーロッパ・アジア） |
| 4 | Epic 魔導兵器バ・ビ・ディ・オン・ファティオス | 3 | 古代（三国志 → クリアすると東アジア・地中海） |
| 5 | Legendary 古代魔導ロボット・ディア・ガ・レティウス | 4 | 時空のはざま（全ノードのクリアも必要） |

- 国 → 時代の順に開く（設定どおり）: タイムマシンの改良で新しい時代の最初のノードが開き、そのノードをクリアすると同じ時代のほかの国が開く（マインがタイムマシンを調整した、という会話つき）
- Common → Uncommon は2つ（設定どおり）。以降は 3・3・4（決め）。2+3+3+4 = 12 で、時空のはざま以外の12ノードをすべてクリアするとちょうど Legendary になる
- どの時点でも、行けるノードのクリアで次の改良に必要なパーツがそろう（行き止まりにならない。テストで確認）
- ノードをクリアしたときは、ステージクリア画面の次に「パーツ獲得」画面。次の合体ロボ（64×64のドット絵）を黒いシルエットで出し、進み具合の割合（パーツ数÷必要数）の分だけドットを下から実体化する。クリア前→後の割合（例: 0% → 50%）、あと何ノードクリアで改良できるか、改良すると行ける場所を表示。そろうと名前が明かされ、改良の演出へ
- ワールドマップのタイムマシン欄にも、次の合体ロボのシルエットと割合を小さく表示
- 旧仕様（パーツがステージごと・各ノード3ステージ）の保存データは、仲間・デッキ・クリアしたステージを残して、タイムマシンをクリアしたノードの数から計算し直す

## 7. レイドボス

- ノードの最終ステージの最後のウェーブで、MCHのレイドボス1体と戦う（設定どおり）。出撃前の会話でボスが現れ、マーケットではテロップ「WARNING / RAID BOSS」、ウェーブのゲージの最後のマスが赤
- **覚醒魔王ファオ・ファオ・ファントム（373/1188）、yamap（1189）、闇魚王（1190）は特別ステージのボス用に取っておくため使わない**（設定どおり）。COVID-19（671/682）も実在の感染症の名前なので使わない（決め）
- 使えるレイドボスは9種類（ディープ・ヨシュカ、チョコラート、チョコラート 2020、ヘイセイ、モンスーン、プーリー・ビースト、ハロウィン・プーリー、真・ディープ・ヨシュカ、ディープ・ヨシュカ フラッグ）。13ノードに足りないので、MCHでも複数あった真・ディープ・ヨシュカ（2種）とフラッグ（4種）は、スキルの違う別の形態として使った（決め）
- ボスは中衛の中央に大きく描く。MCHのアクティブスキル3つを順番に使い（ローテーション）、スキル名を表示。頭上に次のスキルを出し、大技（Final Phase など）は「FINAL」で予告して、発動時は画面いっぱいの帯
- スキルの効果はMCHの説明文とパッシブから決めた（AGIアップ → 次の発動が早い、PHY/INTダウン → 弱体化、AGIダウン → チャージ遅延、出血・毒など。`content/bosses.json`）
- 強さはそのウェーブの通常のエネミー部隊を基準に、パーティHP ×2・効果量 ×1。ボスごとの差は自動プレイでそろえた補正（power）、チュートリアルは ×0.6、古代の後半と時空のはざまは難しさに応じて上乗せ（`js/engine/boss.js` の `BOSS_TUNING`）
- 結果画面でボスをタップすると、ローテーションのスキルと数値を確認できる

## 8. デッキ

- コレクションから最大8種類を選んでデッキにする（決め）。最初は4種類（初期3体＋福沢諭吉）
- **Common か Uncommon を1体以上**入れる（最初のウェーブで1体も買えなくならないように）（決め）
- 出撃前にデッキを確認・編集できる。新しく仲間になったヒーローは自動でデッキに入る（空きがあれば）（決め）
- 新しく仲間になったヒーローには NEW。デッキの外に新しい仲間がいると、デッキのボタンに数を出す
- デッキ画面に、出撃するステージのマーケットに並ぶレアリティの割合（C/U/R/E/L）と、デッキの各レアリティの数を表示。足りないレアリティは赤く、空き枠になる割合も出す
- 「おまかせ」: Common・Uncommon を3種類（Uncommon 優先）＋残りはレアリティの高い順で8種類を選ぶ（自動プレイでよく勝てた組み方）
- 出撃するとき、デッキのせいでマーケットの枠が3割以上空く場合は「デッキを見直す / このまま出撃」を確認する

## 9. チュートリアル（1-1）

1. タイムマシンに乗り込むと、ワールドマップが開ける（最初は近代・日本だけ）
2. ステージ（1-1）を選ぶと、近代日本へタイムスリップする演出 → 福沢諭吉と出会う → 直後にエネミーが現れてバトルへ
3. 最初に選べるのは、MCHウォーリアー・タクティシャン・アーティストと福沢諭吉のみ
4. マインが基本の流れを解説しながら進める
   - ウェーブ1: ヒーローを買う → 枠に置く → バトル開始
   - バトル: ヒーローはチャージがたまると自動でスキル、パーティでHPを共有
   - ウェーブ2: 同じヒーロー3体で合成（Lv2）、エクステンションを選ぶ
   - ウェーブ3: 南京錠で取り置き・更新
   - バトルへ進む案内の前に、まだ買えるヒーロー（GUMが足り、置き場所か合成先がある）があれば、先に「強化しましょう」と案内する
5. 最後のウェーブまで勝つと 1-1 クリア → 樋口一葉・高杉晋作が仲間に
6. 1-3 の最後のウェーブでレイドボス（ディープ・ヨシュカ。弱め）。倒すと近代・日本クリア（チュートリアル完了）、パーツ1つ
7. 完了の会話で、マインがデッキの大切さ（マーケットの空き枠）と「おまかせ」を説明する

## 11. セーブ

- ストーリーの進み具合（プロローグ、クリアしたステージ、仲間、デッキ、パーツ、タイムマシンのレベル、NEW）を保存。形が変わったときは `migrateStory` で直す
- ステージの途中はこれまでと同じく保存し、タイトルの「つづきから」で再開

`node scripts/simulate-story.mjs 64 best` で、ストーリーを最初から自動プレイ（botShop）して、ステージごとのクリア率を見ています（1ステージ5回まで挑戦。デッキの組み方は best（おまかせ）/ novice（初心者用ヒーローだけ）/ auto（組み直さない））。
`--tune '{"cpuIncome":1.5}'` や `--boss '{"hp":2.5}'` で、補正を変えて試せます。

| デッキ | 結果（64周） |
| --- | --- |
| novice（初心者用ヒーローだけ） | 近代・日本は100%。近代・ヨーロッパの 2-7 で止まる（ランクが上がり、マーケットの枠が空く） |
| auto（デッキを組み直さない） | 近代・ヨーロッパで止まる |
| best（おまかせ） | 1回の挑戦でのクリア率はノードの平均で5〜9割、レイドボスは3〜10割。約17%が最後まで到達（自動プレイは人より下手で、5回で諦める） |

- 同じ時代の後から行くノードは、最初のノードで強い仲間が増えるので難しさを上げている
- 古代・東アジアのレイドボスは、自動プレイではほぼ負けない（このノードのエネミー部隊が弱め）。遊んだ感想を見て調整したい
- ストーリーの CPU の補正は `js/engine/balance.js` の `STORY_BALANCE`、レイドボスは `js/engine/boss.js` の `BOSS_TUNING` と `content/bosses.json` の power
