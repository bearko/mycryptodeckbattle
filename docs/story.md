# ストーリーモード 仕様と開発ロードマップ

いただいた世界観・ストーリー・チュートリアルの設定をもとに、ゲームの仕様として整理したものです。
**（決め）** と書いた箇所は、設定に書かれていない部分を開発側で仮に決めたところです。変更しやすいよう、数値や並びはデータ（`js/engine/world.js`）にまとめます。

---

## 1. 世界観

- さまざまな時代・さまざまな国にエネミーが出没し、歴史に介入している
- 歴史上の偉人（ヒーロー）を仲間にしながらエネミーと戦い、世界に平穏を取り戻す

## 2. ストーリー（プロローグ）

1. クリスくんが街を歩いていると、偶然エネミーと遭遇する
2. 未知との出会いに困惑しているところへ、マインが助けに入る（「道との出会い」は「未知との出会い」と解釈）
3. マインがクリスに、世界中の歴史にエネミーが介入していることを説明する
4. マインは自分が発明したタイムマシン（MCHのエクステンション「合体ロボ」シリーズ。最初は Common の **魔導機械エメ・ラ・ルド・テレスター(破)** の名前とアート）を見せ、各時代のヒーローを仲間にしながらエネミーと戦ってほしいとお願いする
5. 幼なじみのよしみで、クリスはマインに協力することにする

## 3. ゲームの構成

```
タイトル
 ├─ ストーリー（新規）
 │   プロローグ → タイムマシン → ワールドマップ → ノード（時代×地域）→ ステージ（X-1〜X-10）→ ウェーブ（マーケット＋バトル）
 └─ フリーバトル（これまでの「10勝でクリア」のクエスト。そのまま残す）（決め）
```

| 用語 | 意味 |
| --- | --- |
| ノード | 時代×地域（例: 近代・日本）。ステージが10個（近代・日本だけ3個）。コード上は area と呼んでいる |
| ステージ | 1回の出撃。決まった数のウェーブを最後まで勝ち抜くとクリア |
| ウェーブ | マーケットでの準備＋エネミー部隊とのバトル1回 |
| レイドボス | ノードの最終ステージの、最後のウェーブで待つ大きなエネミー（MCHのレイドボス） |
| タイムマシン | 合体ロボシリーズ。Common → Uncommon → Rare → Epic → Legendary と改良していく |
| パーツ | タイムマシンの部品。ノードを初めてクリアする（レイドボスを倒す）と1つ手に入る |
| コレクション | 仲間にしたヒーロー |
| デッキ | ステージに連れて行くヒーロー。マーケットにはデッキのヒーローだけが並ぶ |

## 4. ステージ（ウェーブ制）とチームの繰り越し

- ノードのステージ数は10（近代・日本はチュートリアルなので3）。3〜5ステージだと初心者用ヒーローを育てるだけで最後まで進めてしまうため（設定どおり）
- ウェーブ数: 近代・日本は 1-1: 3、1-2: 4、1-3: 5。ほかのノードは X-1〜3: 3、X-4〜7: 4、X-8〜10: 5（決め）
- 最終ステージ（X-10、近代・日本は 1-3）の最後のウェーブはレイドボス（7章）
- 各ウェーブは、これまでと同じ「マーケットで購入・合成・配置 → オートバトル」
- 最後のウェーブまで勝てばステージクリア。ライフは3、負けると1減り、0で撤退（やり直し可）（決め）
- **チームの繰り越し**（設定どおり）: ノードの中では、ステージをクリアしたチーム（パーティと控えのヒーロー・Lv・エクステンション・残りのGUM・取り置き・ステージ数）のまま次のステージへ進む。ノードは 参考作 の1クエストのように、1本の長いランになる
  - 出撃できるのは「次のステージ」だけ（NEXT の印）。負けて撤退したら、そのステージを始めたときのチームでやり直し（決め）
  - 「作り直す」で、ノードの最初のステージから新しいチーム。クリア済みのステージは報酬なしで進む（決め）
  - ライフ・勝利数はステージごとに戻る。デッキはステージの合間に変えてよい（次のステージのマーケットから反映）
  - レイドボスを倒すとノードの繰り越しは終わる（もう一度遊ぶときは X-1 から）
  - 以前の保存データで途中までクリアしたノードは、チームがないので X-1 から（報酬なしで）進み直す
- ステージ選択では、選んでいるステージをもう一度タップすると出撃（設定どおり）。ステージクリア画面には「次のステージへ」（行き先が2つ以上なら「ルートを選ぶ」）

### 4.1 枝分かれのルート（参考作 のような道）

設定どおり、ノードの後半は道が枝分かれし、ステージの特性と自分のパーティの特性を見てルートを選ぶ。

- X-1〜X-4 と X-10（レイドボス）は1本道。**X-5〜X-9 は3つのレーン**（A・B・C、表示は `2-6B` など）に分かれる。近代・日本（チュートリアル）は枝分かれしない
- 道は同じレーンへは必ずつながり、隣のレーンへ渡る道もある（隣り合うレーンの組ごとに「渡らない / 右へ / 左へ」。道どうしは交差しない）。X-4 からは3つのどれへでも、X-9 からは X-10 へ
- 道・ステージの種類・地形・エネミーの傾向はノードIDから決まる（毎回同じ。攻略を覚えられる）（決め）
- 出撃できるのは、いまいるステージから道がつながっている次の行のステージだけ。通った道はマップに明るく描く
- **ステージの種類**
  - 戦闘: いつものステージ
  - 強敵: エネミーの効果量・パーティHP +30%。クリアすると次のステージの最初に宝箱（ライフは出ない）
  - 補給: バトルなし。宝箱を1つ選び、マーケットで買い物をして「出発」。X-9 では出やすい
  - 1つの行に強敵は多くて1つ、補給も多くて1つ（端のレーン）（決め）
- **地形**（そのステージのバトルで両陣営に効く。枝分かれした戦闘・強敵だけ。同じ行では重ならない）
  - 毒の沼（毒 +50%）・血の荒野（出血 +50%）・癒やしの泉（回復・シールド +50%）・決戦の地（ダメージ +30%）・軍師の陣（効果量アップ・チャージ操作・弱体化 +50%）
  - 最前線（前衛 +40%）・見晴らしの丘（後衛 +40%）
  - 勢力の地（朱雀・青龍・玄武・黄竜・白虎のヒーロー +40%。エネミーには勢力がないのでプレイヤーだけ得をする）
- **エネミーの傾向**（そのステージのエネミーの顔ぶれ。レアリティごとに、その種類のスキルを持つエネミーを多めに入れる）
  - 混成部隊 / 毒使いの群れ / 切り裂き部隊（回復・シールドが強い）/ 鉄壁の部隊（ダメージ・弱体化が強い）/ 猛攻部隊（シールド・回復・弱体化が強い）
- **相性の印**: いまのパーティ（繰り越したチーム）で、地形で得をするヒーロー・傾向に強いヒーローの数を ◎（2体以上）○（1体）－（0体）で表示。ステージのカードには種類・地形・傾向・仲間になるヒーロー・強敵の宝箱を出す
- 仲間になるヒーローはレーンに分かれる（補給には出ない）。全部集めるには何度か通る（2周目以降はクリア済みのステージも選べる）
- マーケットに並ぶのはデッキのヒーローだけ。エネミーはノードごとに決まった顔ぶれから出る
- **マーケットの空き枠**（近代・日本以外）: 各枠のレアリティはランクの出現率で決まり、そのレアリティ以上のヒーローがデッキにいないと、その枠は空になる（デッキにいるいちばん近い上のレアリティで代わりに並ぶ）。高レアリティの仲間をデッキに入れないと戦えない（決め。初心者用ヒーローだけで進めてしまわないため）
- **難しさ**（設定どおり、後半のステージほど強い）
  - チームを繰り越すので、ステージ数（ノードに入ってからのウェーブの合計）が進むほど、プレイヤーもエネミー部隊も育つ（エネミーはフリーバトルと同じく、そのステージ数ぶん買い物をした部隊）
  - さらにステージ番号 d（X-1 が 0、X-10 が 9）に応じて、エネミー部隊の効果量とパーティHPを 1あたり +6%、収入を +1（盤面が埋まったあとも後半ほど強くなるように）
  - 時代の差はマーケットランクの上限で付ける: 近代・日本 6、近代 8、近世 10、中世 12、古代・時空のはざま 14（プレイヤーもエネミーも）。古い時代ほど高いレアリティのエネミーが並び、プレイヤーも高いレアリティの仲間が必要になる
  - プレイヤーは毎ウェーブの収入 +2、マーケットランク +d/2。エネミーの追加GUM（フリーバトルの宝箱の代わり）はストーリーでは無し
  - 数値は `js/engine/balance.js` の `STORY_BALANCE`、時代の上限は `js/engine/world.js` の `ERAS`
- プレイヤーはクリスくん固定（プレイヤースキル「ガッツ」: 無料更新）、マインはナビ役（決め）
- 宝箱は出ない（ステージクリアの報酬に置き換え）（決め）

## 5. タイムマシンとパーツ

パーツは**ノード**を初めてクリアしたとき（最終ステージのレイドボスを倒したとき）に1つ手に入ります。途中のステージや2回目以降のクリアでは手に入りません。

| レベル | 合体ロボ | 改良に必要なパーツ | 改良すると行ける場所 |
| --- | --- | --- | --- |
| 1 | Common 魔導機械エメ・ラ・ルド・テレスター(破) | — | 近代（最初は日本。日本をクリアするとヨーロッパ・アメリカ） |
| 2 | Uncommon 魔導海底探索機ジャンヌ・ザ・オメガ | 2 | 近世（日本 → クリアするとヨーロッパ・新大陸と海） |
| 3 | Rare 魔導戦車ジュウ・ザ・トロール | 3 | 中世（日本 → クリアするとヨーロッパ・アジア） |
| 4 | Epic 魔導兵器バ・ビ・ディ・オン・ファティオス | 3 | 古代（三国志 → クリアすると東アジア・地中海） |
| 5 | Legendary 古代魔導ロボット・ディア・ガ・レティウス | 4 | 時空のはざま（全ノードのクリアも必要） |

- 国 → 時代の順に開く（設定どおり）: タイムマシンの改良で新しい時代の最初のノードが開き、そのノードをクリアすると同じ時代のほかの国が開く（マインがタイムマシンを調整した、という会話つき）
- Common → Uncommon は2つ（設定どおり）。以降は 3・3・4（決め）。2+3+3+4 = 12 で、時空のはざま以外の12ノードをすべてクリアするとちょうど Legendary になる
- どの時点でも、行けるノードのクリアで次の改良に必要なパーツがそろう（行き止まりにならない。テストで確認）
- ノードをクリアしたときは、ステージクリア画面の次に「パーツ獲得」画面。次の合体ロボ（64×64のドット絵）を黒いシルエットで出し、進み具合の割合（パーツ数÷必要数）の分だけドットを下から実体化する。クリア前→後の割合（例: 0% → 50%）、あと何ノードクリアで改良できるか、改良すると行ける場所を表示。そろうと名前が明かされ、改良の演出へ
- ワールドマップのタイムマシン欄にも、次の合体ロボのシルエットと割合を小さく表示
- 旧仕様（パーツがステージごと・各ノード3ステージ）の保存データは、仲間・デッキ・クリアしたステージを残して、タイムマシンをクリアしたノードの数から計算し直す

## 7. レイドボス

- ノードの最終ステージの最後のウェーブで、MCHのレイドボス1体と戦う（設定どおり）。出撃前の会話でボスが現れ、マーケットではテロップ「WARNING / RAID BOSS」、ウェーブのゲージの最後のマスが赤
- **覚醒魔王ファオ・ファオ・ファントム（373/1188）、yamap（1189）、闇魚王（1190）は特別ステージ（7.1）のボスにして、ノードのレイドボスには使わない**（設定どおり）。COVID-19（671/682）も実在の感染症の名前なので使わない（決め）
- 使えるレイドボスは9種類（ディープ・ヨシュカ、チョコラート、チョコラート 2020、ヘイセイ、モンスーン、プーリー・ビースト、ハロウィン・プーリー、真・ディープ・ヨシュカ、ディープ・ヨシュカ フラッグ）。13ノードに足りないので、MCHでも複数あった真・ディープ・ヨシュカ（2種）とフラッグ（4種）は、スキルの違う別の形態として使った（決め）
- ボスは中衛の中央に大きく描く。MCHのアクティブスキル3つを順番に使い（ローテーション）、スキル名を表示。頭上に次のスキルを出し、大技（Final Phase など）は「FINAL」で予告して、発動時は画面いっぱいの帯
- スキルの効果はMCHの説明文とパッシブから決めた（AGIアップ → 次の発動が早い、PHY/INTダウン → 弱体化、AGIダウン → チャージ遅延、出血・毒など。`content/bosses.json`）
- 強さはそのウェーブの通常のエネミー部隊（エクステンション・強化込みの効果量とチャージの速さ）を基準に、パーティHP ×3・効果量 ×1.3。チュートリアルは ×0.6。ボスごとの差は自動プレイでそろえた補正（power）（`js/engine/boss.js` の `BOSS_TUNING`）
- ボスは1体なので、相手の弱体化・チャージ遅延が集中しないよう、7割軽減する（`BOSS_RESIST`）
- 結果画面でボスをタップすると、ローテーションのスキルと数値を確認できる

### 7.1 特別ステージ（特異点）

設定どおり、ファオ・yamap・闇魚王は特別ステージのボスにした。歴史がねじれて「ありえない存在」が生まれた場所を**特異点**と呼ぶ（決め）。

| 特別ステージ | 開く条件 | 地図 | ボス | ステージ（ウェーブ数・地形・エネミーの傾向） |
| --- | --- | --- | --- | --- |
| EX1 コルシカの特異点 | 近代・ヨーロッパをクリア | 近代 | yamap（パッシブ「コルシカの悪魔」から、ナポレオンの故郷に） | 4・5・5。猛攻部隊、決戦の地、最前線 |
| EX2 深海の特異点 | 近世・新大陸と海をクリア | 近世 | 闇魚王（海の底の王） | 4・5・5。毒使いの群れ、毒の沼、癒やしの泉 |
| EX3 魔王の特異点 | 時空のはざまをクリア | 時空のはざま | 2ステージ目にファオ・ファントム、最後に覚醒魔王ファオ | 5・5・6。切り裂き部隊、軍師の陣、鉄壁の部隊 |

- 3ステージの1本道（枝分かれなし）。チームはノードと同じく繰り越し、最初のステージは新しいチーム
- 仲間・パーツは出ない（寄り道のやりこみ）。クリアすると地図のピンが金色になる（決め）
- 開くまで地図に出さない。開いたノードのクリアの会話の最後に、マインが特異点の出現を告げる。地図では回転する輪とグリッチするボスの絵（`docs/ui-design.md` 3.9）
- マーケットランクの上限は、その時代より高い（EX1: 10、EX2: 12、EX3: 14）。エネミーの強さの上乗せ（difficulty）も 1〜2
- ボスのスキルはMCHの説明文から（`content/bosses.json` の special: true）
  - yamap: アップデート（魅了 → チャージ遅延）/ マス・アウテージ type:INT（大技）/ type:FEAR（恐怖 → 弱体化）
  - 闇魚王・ファオ・ファントム: テムプティング・アドバタイズ（魅了 → チャージ遅延・弱体化）/ インタラプト 3.0（全体ダメージ＋毒。大技）
  - 覚醒魔王ファオ: 魔王の祝福（睡眠・恐怖・混乱 → チャージ遅延・弱体化）/ 魔王の鼓動（AGIアップ → シールド＋ダメージ）/ 魔王の晩餐（大技）
- 魔王ファオを倒すとエンディング（「THE END」）。ファオがエネミーを歴史に送り込んでいた黒幕、という物語の締めくくり（決め）
- yamap・闇魚王の絵は描き込みの細かい大きなイラストなので、256pxに縮めて使う（ほかのボスは128pxのドット絵）

### 7.2 ノードごとの台本

- 各ノードに専用の台本（`js/story/node-scripts.js`）: 到着の会話、看板ヒーロー（1・5・10ステージ目）との出会い、レイドボスの第一声、クリアの会話
- 看板ヒーロー以外の出会うヒーロー（約120人）には、自己紹介の一言（名言や人物像をふまえた創作）。返事は4種類から、ヒーローごとに決まった1つ
- 台詞は史実・伝承の人物像をふまえた創作。物語は「ヨーロッパで黒幕の存在に気づく → 海の底の変な気配 → すべての時代を守る → はざまの奥に魔王 → 特異点で魔王を倒してエンディング」とつながる（決め）
- テストで、出会うヒーロー全員にセリフがあること、台本のヒーロー・ボスが実在することを確認

### 7.3 ノードごとのBGM

MCHのBGMは4曲（PvP・ランド・PvE・レイド）しかないため、曲の組み合わせと時代の「音色」でノードごとに変える（決め）。

- 時代の音色（`js/engine/world.js` の `ERAS[].tone`）: 近代はそのまま、近世は少し低く（再生速度0.96）、中世はさらに低く高音を少し削る（0.93・7000Hz）、古代はいちばん低くこもった音（0.9・5200Hz）、時空のはざまは少し高く（1.06）
- 同じ時代のノードでは、マーケット・バトルの曲を入れ替える（例: 近代・アメリカと近世・新大陸と海のバトルは PvP の曲。`area.music`）
- レイドボスのウェーブ（マーケット・バトル）と、ボスが現れる会話、特別ステージのバトルはレイドの曲（いままで使っていなかった `raid.mp3`）
- 再生速度は音の高さも一緒に変え（preservesPitch: false）、高音を削るのは Web Audio のローパスフィルター（使えないブラウザではそのまま鳴る）

## 8. デッキ

- コレクションから最大8種類を選んでデッキにする（決め）。最初は4種類（初期3体＋福沢諭吉）
- **Common か Uncommon を1体以上**入れる（最初のウェーブで1体も買えなくならないように）（決め）
- 出撃前にデッキを確認・編集できる。新しく仲間になったヒーローは自動でデッキに入る（空きがあれば）（決め）
- 新しく仲間になったヒーローには NEW。デッキの外に新しい仲間がいると、デッキのボタンに数を出す
- デッキ画面に、出撃するステージのマーケットに並ぶレアリティの割合（C/U/R/E/L）と、デッキの各レアリティの数を表示。足りないレアリティは赤く、空き枠になる割合も出す
- 「おまかせ」: Common 2種類と Uncommon 1種類（最初の10GUMで2体買える）＋残りはレアリティの高い順で8種類を選ぶ
- 出撃するとき、デッキのせいでマーケットの枠が3割以上空く場合は「デッキを見直す / このまま出撃」を確認する

## 9. チュートリアル（1-1）

1. タイムマシンに乗り込むと、ワールドマップが開ける（最初は近代・日本だけ）
2. ステージ（1-1）を選ぶと、近代日本へタイムスリップする演出 → 福沢諭吉と出会う → 直後にエネミーが現れてバトルへ
3. 最初に選べるのは、MCHウォーリアー・タクティシャン・アーティストと福沢諭吉のみ
4. マインが基本の流れを解説しながら進める
   - ウェーブ1: ヒーローを買う → 枠に置く → バトル開始
   - バトル: ヒーローはチャージがたまると自動でスキル、パーティでHPを共有
   - ウェーブ2: 同じヒーロー3体で合成（Lv2）、エクステンションを選ぶ
   - ウェーブ3: 南京錠で取り置き・更新
   - バトルへ進む案内の前に、まだ買えるヒーロー（GUMが足り、置き場所か合成先がある）があれば、先に「強化しましょう」と案内する
5. 最後のウェーブまで勝つと 1-1 クリア → 樋口一葉・高杉晋作が仲間に
6. 1-3 の最後のウェーブでレイドボス（ディープ・ヨシュカ。弱め）。倒すと近代・日本クリア（チュートリアル完了）、パーツ1つ
7. 完了の会話で、マインがデッキの大切さ（マーケットの空き枠）と「おまかせ」を説明する

### バランス（自動プレイでの確認）

`node scripts/simulate-story.mjs 24 best` で、ストーリーを最初から自動プレイ（botShop）して、ステージごとのクリア率を見ています。
ノードの中はチームを繰り越し、負けたらそのステージの開始時のチームで5回まで、だめなら1回だけ X-1 から作り直します。
自動プレイは人の遊び方に寄せて、合成でエクステンション（戦闘に効くもの）を選び、枠が埋まってGUMが余ったら弱いヒーローを売って高いレアリティへ入れ替えます。
枝分かれでは、地形・エネミーの傾向とパーティの相性（◎○－の数）、補給（少し好む）、強敵（少し避ける）、新しい仲間を見てルートを選びます。
デッキの組み方は best（おまかせ。ルートは相性で選ぶ）/ straight（best と同じデッキで、ルートは同じレーンをまっすぐ）/ novice（初心者用ヒーローだけ）/ auto（組み直さない）。`--tune '{"cpuPower":8}'` や `--boss '{"hp":3.5}'` で補正を変えて試せます。

| デッキ | 結果（24周） |
| --- | --- |
| best（おまかせ・相性でルートを選ぶ） | 75%が最後まで到達。ステージの種類ごとのクリア率: 戦闘 85%・強敵 56%・補給 100%・レイドボスのステージ 69% |
| straight（ルートを選ばない） | 42%が最後まで到達（強敵を避けられず、相性の悪い地形でも進むため）。戦闘 87%・強敵 49%・レイドボスのステージ 68% |
| novice（初心者用ヒーローだけ） | 近代・ヨーロッパで止まる（強敵は勝てない） |
| auto（デッキを組み直さない） | 約40%が最後まで到達（近代・日本の Epic・Uncommon を育てて進む） |

- ルートの選び方で結果が大きく変わる（設定どおり、特性を見て選ぶ意味がある）
- いちばん難しいのは近世以降のレイドボス（時代が変わってランクの上限が上がり、チームも作り直しになるため）
- 特別ステージ（16周、開いた直後に挑む）: ボスのウェーブの勝率（1回の挑戦あたり）は yamap 37%・闇魚王 38%・ファオ・ファントム 75%・覚醒魔王ファオ 47%。たどり着いた周はどれも5回の挑戦のうちにクリア
- ストーリーの補正は `js/engine/balance.js` の `STORY_BALANCE`、レイドボスは `js/engine/boss.js` の `BOSS_TUNING` と `content/bosses.json` の power
