# ストーリーモード 仕様と開発ロードマップ

いただいた世界観・ストーリー・チュートリアルの設定をもとに、ゲームの仕様として整理したものです。
**（決め）** と書いた箇所は、設定に書かれていない部分を開発側で仮に決めたところです。変更しやすいよう、数値や並びはデータ（`js/engine/world.js`）にまとめます。

---

## 1. 世界観

- さまざまな時代・さまざまな国にエネミーが出没し、歴史に介入している
- 歴史上の偉人（ヒーロー）を仲間にしながらエネミーと戦い、世界に平穏を取り戻す

## 2. ストーリー（プロローグ）

1. クリスくんが街を歩いていると、偶然エネミーと遭遇する
2. 未知との出会いに困惑しているところへ、マインが助けに入る（「道との出会い」は「未知との出会い」と解釈）
3. マインがクリスに、世界中の歴史にエネミーが介入していることを説明する
4. マインは自分が発明したタイムマシン（MCHのエクステンション「合体ロボ」シリーズ。最初は Common の **魔導機械エメ・ラ・ルド・テレスター(破)** の名前とアート）を見せ、各時代のヒーローを仲間にしながらエネミーと戦ってほしいとお願いする
5. 幼なじみのよしみで、クリスはマインに協力することにする

## 3. ゲームの構成

```
タイトル
 ├─ ストーリー（新規）
 │   プロローグ → タイムマシン → ワールドマップ → エリア（時代×地域）→ ステージ（X-1〜X-3）→ ウェーブ（マーケット＋バトル）
 └─ フリーバトル（これまでの「10勝でクリア」のクエスト。そのまま残す）（決め）
```

| 用語 | 意味 |
| --- | --- |
| エリア | 時代×地域（例: 近代・日本）。ステージが3つ |
| ステージ | 1回の出撃。決まった数のウェーブを最後まで勝ち抜くとクリア |
| ウェーブ | マーケットでの準備＋エネミー部隊とのバトル1回 |
| タイムマシン | 合体ロボシリーズ。Common → Uncommon → Rare → Epic → Legendary と改良していく |
| パーツ | タイムマシンの部品。ステージを初めてクリアすると1つ手に入る |
| コレクション | 仲間にしたヒーロー |
| デッキ | ステージに連れて行くヒーロー。マーケットにはデッキのヒーローだけが並ぶ |

## 4. ステージ（ウェーブ制）

- ステージは決まった数のウェーブで構成（X-1: 3ウェーブ、X-2: 4ウェーブ、X-3: 5ウェーブ）（決め）
- 各ウェーブは、これまでと同じ「マーケットで購入・合成・配置 → オートバトル」
- 最後のウェーブまで勝てばステージクリア。ライフは3、負けると1減り、0で撤退（やり直し可）（決め）
- マーケットに並ぶのはデッキのヒーローだけ。エネミーはエリアごとに決まった顔ぶれから出る
- 難しさはエリアの時代・地域と、ステージ番号で上がる（エネミーの強さ・マーケットランク）
- プレイヤーはクリスくん固定（プレイヤースキル「ガッツ」: 無料更新）、マインはナビ役（決め）
- 宝箱は出ない（ステージクリアの報酬に置き換え）（決め）

## 5. タイムマシンとパーツ

| レベル | 合体ロボ | 改良に必要なパーツ | 行けるようになる場所 |
| --- | --- | --- | --- |
| 1 | Common 魔導機械エメ・ラ・ルド・テレスター(破) | — | 近代・日本 |
| 2 | Uncommon 魔導海底探索機ジャンヌ・ザ・オメガ | 2 | 近代のほかの国（ヨーロッパ・アメリカ） |
| 3 | Rare 魔導戦車ジュウ・ザ・トロール | 3 | 近世（日本・ヨーロッパ・新大陸と海） |
| 4 | Epic 魔導兵器バ・ビ・ディ・オン・ファティオス | 4 | 中世（日本・ヨーロッパ・アジア） |
| 5 | Legendary 古代魔導ロボット・ディア・ガ・レティウス | 5 | 古代（三国志・東アジア・地中海） |

- パーツの必要数は Common → Uncommon が2（設定どおり）、以降は3・4・5（決め）
- ステージクリア画面の次に「パーツ獲得」画面。次の合体ロボ（64×64のドット絵）を黒いシルエットで出し、進み具合の割合（パーツ数÷必要数）の分だけドットを下から実体化する。クリア前→後の割合（例: 0% → 50%）、あと何ステージクリアで改良できるか、改良すると行ける場所を表示。そろうと名前が明かされ、改良の演出へ
- ワールドマップのタイムマシン欄にも、次の合体ロボのシルエットと割合を小さく表示
- 必要数がそろうと、マインがタイムマシンを改良する演出 → 新しい国・時代が開く（国 → 時代の順）
- 行ける場所は「タイムマシンのレベル」と「チュートリアル（近代・日本）のクリア」で決まる
- 全エリアをクリアすると、おまけエリア「時空のはざま」が開く（決め）

- 時代・地域は史実の年代と、MCHの属性（日本・戦国・幕末・三国志・ギリシャなど）から割り振った（決め）。伝説上の人物は物語の舞台の時代に置いた

## 7. デッキ

- コレクションから最大8種類を選んでデッキにする（決め）。最初は4種類（初期3体＋福沢諭吉）
- 出撃前にデッキを確認・編集できる。新しく仲間になったヒーローは自動でデッキに入る（空きがあれば）（決め）

## 8. チュートリアル（1-1）

1. タイムマシンに乗り込むと、ワールドマップが開ける（最初は近代・日本だけ）
2. ステージ（1-1）を選ぶと、近代日本へタイムスリップする演出 → 福沢諭吉と出会う → 直後にエネミーが現れてバトルへ
3. 最初に選べるのは、MCHウォーリアー・タクティシャン・アーティストと福沢諭吉のみ
4. マインが基本の流れを解説しながら進める
   - ウェーブ1: ヒーローを買う → 枠に置く → バトル開始
   - バトル: ヒーローはチャージがたまると自動でスキル、パーティでHPを共有
   - ウェーブ2: 同じヒーロー3体で合成（Lv2）、エクステンションを選ぶ
   - ウェーブ3: 南京錠で取り置き・更新
   - バトルへ進む案内の前に、まだ買えるヒーロー（GUMが足り、置き場所か合成先がある）があれば、先に「強化しましょう」と案内する
5. 最後のウェーブまで勝つと 1-1 クリア → 樋口一葉・高杉晋作が仲間に、パーツ1つ
6. 1-3 までクリアで近代・日本クリア（チュートリアル完了）

## 9. 画面

| 画面 | 内容 |
| --- | --- |
| タイトル | ストーリー / フリーバトル / つづきから / 遊び方 |
| シーン | 背景・キャラクターの立ち絵・名前つきの会話。タップで進む。SKIP あり |
| ワールドマップ | 時代のタブ（近代・近世・中世・古代）、地域のピン（地図上）、タイムマシンとパーツの進み具合 |
| ステージ選択 | 定番アクションや参考作のように、タイルが線でつながった道。クリア済み・挑戦可・未開放を表示 |
| デッキ | コレクションから最大8種類を選ぶ |
| ステージ中 | これまでのマーケット・バトル。HUDにステージ番号（1-1）とウェーブ（2/3） |
| クリア / 撤退 | 仲間になったヒーロー、手に入れたパーツ、タイムマシンの改良 |

## 10. セーブ

- ストーリーの進み具合（プロローグ、クリアしたステージ、仲間、デッキ、パーツ、タイムマシンのレベル）を保存
- ステージの途中はこれまでと同じく保存し、タイトルの「つづきから」で再開

## 11. 確認したい点（仮で決めて進めています）

1. フリーバトル（これまでの10勝クエスト）を残すか、ストーリーに一本化するか（いまは残す）
2. ウェーブ数（3/4/5）・ライフ3・デッキ8種類の数値
3. パーツの分割数（Uncommon 以降を 3/4/5 にした）と、1ステージ1パーツ（2回目以降のクリアは報酬なし）
4. ヒーローの時代・地域の割り振り（特に伝説上の人物、サトシ・ナカモトや ETHEREMON などの扱い）
5. ストーリーでのプレイヤーをクリスくん固定にしてよいか（MAI の登場場面）

### バランス（自動プレイでの確認）

`node scripts/simulate-story.mjs 30` で、ストーリーを最初から自動プレイ（botShop）して、ステージごとのクリア率を見ています。
目安は 1-1 がほぼ100%、1-2 が約8割、1-3 が約6割、以降は1回の挑戦で5〜7割（自動プレイは人より下手なので、人はもう少し勝てる想定）。
ストーリーの CPU は、デッキで種類が絞られる分だけ控えめにしています（`js/engine/cpu.js` の `storyCpuTuning`）。
